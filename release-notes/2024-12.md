### Vermerke
Es gibt ein neues System, mit dem in Zukunft verschiedenste *Vermerke* von Foodsaver:innen verwaltet werden sollen. Das könnten Probeabholungen, Hygieneschulungen und vieles mehr sein. ( !3317, !3318, !3348, !3604)
Die Enwicklung dieses Systems ist noch nicht abgeschlossen und daher unvollständig.

### Vertrauensbananen
- Vertrauensbananen bleiben erhalten, wenn die vergebenden Nutzer:innen ihr Profil löschen. ( !3492)
- Vergebene Vertrauensbananen können jetzt im eigenen Profil eingesehen werden ( !3581, !3676)
- Vertrauensbananen können zurückgezogen werden. ( !3728)

### Pinnwände
- Auf Pinnwänden können jetzt weitere Posts nachgeladen werden. ( !3580)
- Betriebspinnwände wurden an die übrigen Pinnwände auf der Plattform angeglichen. ( !3577)

### Karte
- Die Auswahl der auf der Karte angezeigten Betriebe wurde überarbeitet. ( !3596 )
- Die Ortssuche wurde von Komoot auf Geoapify gewechselt. ( !3492)
- Kartenmarker werden im Browser zwischengespeichert und müssen seltener nachgeladen werden. ( !3712)
- Auf der Karte können sich Botschafter:innen jetzt auch die Foodsaver:innen ihres Bezirks anzeigen lassen. Dadurch können sie sich einen Überblick verschaffen, wo wie viele aktive foodsaver zur Verfügung stehen. ( !3714)

### Dark Mode sowie weitere Themes
Es gibt jetzt einen Dark Mode, der die Webseite in dunklen Farben darstellt. Dieser kann in den Einstellungen aktiviert werden. Darüber hinaus gibt in der Zukunft die Möglichkeit weitere Themes zu erstellen.
Die Themes könnt ihr im Profilmenü neben der Sprachauswahl finden.

### Digitale Foodsharing Ausweise
Es ist nun möglich, sich den Foodsharing-Ausweis in Google Pay oder Apple Wallet zu speichern. ( !3591 ) Diese können als digitale Version des Ausweises genutzt werden.

### Bezirke
- Verlassen des Bezirks ist mit einem Timer verbunden, um aus Versehen verlassen zu verhindern. ( !3562 )
- Für Forenthreads in moderierten Bezirken, die aktiviert werden müssen, wird eine Glockenbenachrichtigung an die Botschafter\*innen des Bezirks gesendet. (!3703)

### Essenskörbe
- Verbesserungen Bilder-Upload für Essenskörbe: ( !3304)
    - Essenskörbe können nun mehrere Bilder haben.
    - Die Qualität hochgeladener Bilder ist jetzt besser.

### Hygienequiz
Immer mehr Betriebe erwarten von den Foodsaver:innen, dass sie im Umgang mit Lebensmittelhygiene geschult sind. Bislang wurde das in den meinsten Bezirken mit erheblichem Verwaltungsaufwand über online verfügbare Schulungen (bspw. bei Metro) geregelt.
In diesem Update erhält die Plattform daher endlich ihre eigene Hygieneschulung. Im Details bedeutet das:
- Alle Foodsaver:innen können an einem "Hygienequiz" teilnehmen, ähnlich dem Quiz für Foodsaver:innen oder Betriebsverantwortliche. Alle Informationen, die zum Beantworten der Quizfragen nötig sind, werden in einem Hygiene-Handbuch für foodsharing zusammengefasst. Dieses Handbuch wird noch weiter überarbeitet, ist aber schon jetzt unter [Link einfügen](#) verfügbar. ( !3540)
- Anders als bei den anderen Quizzes, kann man nicht endgültig durch das Hygienequiz druchfallen - wenn ihr das Quiz nicht besteht, habt ihr einen zweiten Versuch, und könnt ab da jeden Tag ein weiteres mal Versuchen, das Quiz zu bestehen. ( !3618)
- Sobald ihr das Quiz besteht, erhaltet ihr einen "Hygiene-Vermerk", den ihr auch in euerem Profil sehen könnt. Dieser zeigt euch, dass ihr aktuell eine gültige Hygieneschulung habt. Andere Nutzer:innen können das aktuell nicht sehen. ( !3722)
- Das Bestehen des Quizzes ist ein Jahr gültig. Bereits nach 9 Monaten könnt ihr das Quiz erneut durchführen, um euer Wissen aufzufrischen.
- Betriebsverantwortliche haben die Möglichkeit, für ihren Betrieb einzustellen, dass ein gültiges Hygienezertifikat notwendig ist. Das bewirkt folgendes: ( !3756)
    - Nur Foodsaver:innen mit gültigem Hygienezertifikat können sich für das Betriebsteam bewerben.
    - Nur Foodsaver:innen mit gültigem Hygienezertifikat können sich in Slots eintragen.
    - Alle anderen werden an den entsprechenden Stellen auf das Hygienequiz verwiesen.

Die Umsetzung dieses umfangreichen Projektes, das bereits im Januar begonnen hat, hat außerdem den Grundstein gelegt, weitere Schulungen und ähnliches direkt auf der Plattform einzubauen.

Vielen Dank an die überregionale AG Hygiene (allen voran [Jörg](/user/150506/profile)), welche die gesamte inhaltliche Arbeit an diesem Projekt geleistet hat; von der Sammlung aller relevanten Inhalte bis zur Konzeption der Quizfragen. Ohne euch wäre dieses Projekt nicht möglich gewesen.


### Weitere Änderungen
- Wenn BOTs auf der Mitglieder-Seite eines Bezirks nach Mitgliedern suchen, die schon länger nicht mehr aktiv waren, können sie jetzt einen größeren Zeitraum angeben (12 Monate -> 36 Monate). (!3568)
- Das eigene Passwort kann in den Profileinstellungen geändert werden ( !3435)
- Das Feld "Öffentlich Infos" im Betrieb unterstützt jetzt Markdown. Bei der Eingabe wird die aktuelle Anzahl der Zeichen angezeigt und bei *520 Zeichen (vorher 180)* begrenzt. ( !3389, !3646)
- Betriebskategorien können jetzt über das Menü Systemadministration verwaltet werden ( !3420)
- In den Betriebseinstellungen sind die Optionen Sticker und Presse auf ein Dropdown mit den Optionen "Noch nicht geklärt", Ja und Nein geändert worden. ( !3623)
- Im Quiz-Editor können Quizze jetzt getestet werden. ( !3612)
- Botschafter:innen können jetzt den vorherigen Stammbezirk und die letzte Abholung im Profil der Foodsaver:innen ihres Bezirks einsehen. ( !3675) 
- Nutzer erhalten jetzt Glocken, wenn sie in Forenposts erwähnt werden. Wer das nicht möchte, kann diese Glocken in den Benachrichtigunseinstellungen deaktivieren. ( !3671)
- Im der Markdown-Eingabe ist es jetzt leichter, Nutzer zu verlinken ( !3670) 
- Der Button in der Chat-Nachrichten-Liste im Menü, mit dem man eine Nachricht als gelesen/ungelesen markieren kann, ist jetzt leichter zu erkennen und wird auf Mobilgeräten immer angezeigt. (!3659)
- Mitgliederseiten sind vorübergehend für große Bezirke (Europa und Deutschland, Österreich, Schweiz) deaktiviert, da diese den Server überlasten. ( !3677)
- Der Vertrauensbananenzähler im Nutzerprofil wurde angepasst um mehr seinen Geschwisterzählern zu gleichen.
- Die [Devdocs](https://devdocs.foodsharing.network/) haben wurden von Docusaurus zu VitePress migriert. Dadurch sind sie schneller, offline verfügbar und haben ein neues Design. ( !3640 )
- Wenn man mehrere Tabs der foodsharing-Seite gleichzeitig geöffnet hat, werden Login-Daten, Chatnachrichten und Glocken jetzt zwischen diesen Tabs synchronisiert. ( !3693)
- Moderator:innen eines Forums können jetzt Beiträge anderer Nutzer:innen ausblenden, wenn diese Option für den Bezirk aktiviert ist. Ausgeblendete Beiträge können wiederhergestellt werden. ( !3419 )
- Teamanfragen werden jetzt nach Zeitpunkt der Beitrittsanfrage sortiert. ( !3694)
- Das Fenster für Bewerber:innen eines Betriebs wird jetzt auf auf schmalen Bildschirmen korrekt angezeigt. ( !3695)
- Bei Beiträgen in Fairteilern werden wieder Benachrichtungen via E-Mail und Glocke versendet. ( !3690 )
- Bei Bewerbungen auf Betriebsteams ist es jetzt möglich, eine optionale Bewerbungsnachricht mitzuschicken. ( !3461)
- Abstimmungen des Typs "Wahlmöglichkeiten jeweils Zustimmung / Enthaltung / Ablehnung" ("Daumen") können auch mit nur einer Wahlmöglichkeit erstellt werden. ( !3684)
- Das Abstimmungsmodul wurde verbessert ( !3716)
- Administratoren einer Arbeitsgruppe können nicht mehr die Eigenschaften von Untergruppen modifizieren ( !3701)
- Die Handynummer war ungewollt im Registrierungsformular ein Pflichtfeld. Dies wurde behoben. ( !3726)
- Die Eingabe des Geburtsdatums bei der Registrierung und in den Profileinstellungen ist jetzt auf kleineren Displays besser möglich ( !3738)
- Push-Benachrichtigungen für Chat-Nachrichten können jetzt einfach über das Chat-Menü aktiviert werden. ( !3375)
- Beim Verfassen einer neuen Email können jetzt auch Empfängeradressen hinzugefügt werden, die den ersten Teil der Mailadresse in Anführungszeichen und mit Sonderzeichen haben. (!13757)
- Die Fairteiler-Seite wurde überarbeitet. ( !3730)
- Die Support- und Kontaktlinks wurden auf unser neues Support System umgestellt (!3803)
