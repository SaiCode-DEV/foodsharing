Es ist mal wieder so weit! Das ehrenamtliche Entwickler-Team von foodsharing hat für euch das **Release Laugenbrezel** fertiggestellt!

Wie immer haben wir für euch eine Liste der wichtigsten Änderungen aus den letzten 4 Monaten Entwicklungsarbeit zusammengestellt. All die Fehlerbehebungen, Änderungen an Texten und nach außen hin unsichtbaren Verbesserungen am Code sind zwar sehr wichtig, aber für die meisten eher nicht so spannend. Wer dennoch Interesse daran hat, kann einen Blick in das vollständige [Changelog](/content?sub=changelog) werfen, wo alle erledigten Aufgaben und verantwortlichen Personen verlinkt sind. Jeder Eintrag enthält auch einen Link zu der relevanten Änderung am Open Source Code der foodsharing-Webseite.


### Chats
- Chats zeigen jetzt die Anzahl die ungelesenen Nachrichten an ( !3153)
- Chats können einzeln als gelesen oder ungelesen markiert werden ( !3153)

### E-Mail-Postfächer
Hier gibt es einige Verbesserungen ( !3108, !3203, !3258, !3266, !3278 ):
- Die E-Mail-Postfächer werden alphabetisch sortiert
- Der Link im Menü der Bezirksseite führt direkt zum entsprechenden Postfach des Bezirks
- E-Mails können weitergeleitet werden (bisher nur ohne Anhang)
- Das Markieren als gelesen/ungelesen funktioniert wieder
- E-Mails im Papierkorb werden nicht mehr auf dem Dashboard angezeigt
- E-Mails werden seitenweise angezeigt
- Ein Fehler im E-Mail-Modul wurde behoben, wodurch die Mailadressen im Empfängerfeld in der Desktop-Ansicht über den Rand gingen. ( !3226)

### Betriebe
- Die Betriebsteamliste wurde überarbeitet. Es gibt nun keinen verwirrenden "BV-Modus" mehr, sondern alle Infos und Optionen auf einen Blick. ( !3207)
- Beim Bestätigen von Abholungen ist es nun möglich, sich die Termine anzeigen zu lassen, für welche sich der jeweilige Nutzer beim Betrieb eingetragen hat ( !3213).
- Im Adress-Abschnitt der Betriebsseite ist der Betrieb auf der Karte verlinkt ( !3113)
- Die Auswahl von Datum und Zeit beim manuellen Anlegen von Slots wird auf dem Smartphone wieder vollständig angezeigt ( !3231)
- Der Eintragungszeitpunkt von Slots wird auch beim Wechsel von Winter- / Sommerzeit angezeigt ( !3228)

### Weitere neue Funktonen
- Ein Spendenbanner wurde hinzugefügt, mit der Möglichkeit diesen für 24 Stunden auszublenden ( !2930)
- Forenthreads können von Administrator:innen besser sortiert werden. ( !3205)

### Weitere Verbesserungen an der Nutzungsoberfläche
- Das Menü bleibt auf mobilen Endgeräten oben. ( !3054)
- Sämtliche Pinnwände wurden überarbeitet. Sie nutzen jetzt Markdown und erlauben einen besseren Bilder-Upload. ( !3045, !3112)
- Die Seite zur Erstellung von Betrieben wurde mit aktuellen Technologien neu gebaut ( !3136)
- Die Übersicht der Arbeitsgruppen wurde mit aktuellen Technologien neu gebaut. Zusätzlich gibt es eine Suchfunktion. ( !3162)
- Foreneinträge werden beim Scrollen nicht mehr automatisch nachgeladen. Es kann jetzt über eine Navigation unten geblättert werden ( !3229)
- Verschiedene Glocken werden jetzt gruppiert. ( !3073)
- Die [Übersichtsseite aller Bezirke](/content?sub=communities) wurde überarbeitet. Sie wird jetzt automatisch aktuell gehalten. ( !3143)
- Auf der Seite von Fairteilern zeigt eine Karte den Standort an. Außerdem verweist ein Link auf den Standort auf der großen Karte. ( !3097)
- Das Ändern der Kette in den Betriebseinstellungen wurde in ein Pop-up mit Suchfunktion angepasst. ( !2863)

Neben all diesen schon fertigen Änderungen, arbeiten wir auch jetzt schon an vielen weiteren neuen Funktionen und Verbesserungen, die es nicht mehr in dieses Release geschafft haben. Aber die nächste Version kommt in wenigen Monaten!
