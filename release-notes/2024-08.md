Es ist mal wieder so weit! Das ehrenamtliche Entwickler-Team von foodsharing hat für euch das **Release Mandarine** fertiggestellt!

Wie immer haben wir für euch eine Liste der wichtigsten Änderungen aus den letzten 4 Monaten Entwicklungsarbeit zusammengestellt. Darüber hinaus gab es wie immer viele Fehlerbehebungen, kleinere Verbesserungen, Optimierungen am Code und Aktualisierungen. Wer Interesse an den Details hat, kann einen Blick in das vollständige [Changelog](/content?sub=changelog) werfen, wo alle erledigten Aufgaben und verantwortlichen Personen verlinkt sind. Jeder Eintrag enthält auch einen Link zu der relevanten Änderung am Open Source Code der foodsharing-Webseite.

### Forum
- Forenbeiträge können besser verlinkt werden: ( !3293)
  - Links zu einzelnen Beiträgen können direkt kopiert werden.
  - Das Forum springt besser zum verlinkten Forenpost.
  - Der verlinkte Post wird hervorgehoben angezeigt.
- Der Name von Forenbeiträgen steht nun auch im Titel des Tabs. ( !3338)

### Quiz
Das Quiz-Modul wurde von Grund auf erneuert. Neben einigen Verbesserungen in der Nutzbarkeit ebnet das vor allem den Weg für weitere Quizze in der Zukunft, wie bspw. eine in die Plattform integrierte Hygieneschulung. ( !3119, !3329, !3418, !3422)

### Karte
- Die Karte wurde neu gebaut. Ihre Popups sind jetzt auch auf mobilen Geräten vollständig sichtbar. ( !3230)
- Auf der Karte ist ein neuer Button sichtbar, mit dem die Karte auf die aktuelle Position des Geräts zentriert werden kann. ( !3357)
- Für Fairteiler wird jetzt ebenfalls ein Popup mit den wichtigsten Informationen angezeigt ( !3360)
- Der Name von Markern auf der Karte wird als Tooltip angezeigt. ( !3466)
- Bei der Bewerbung für ein Betriebsteam wird jetzt die Entfernung des eigenen Wohnortes zum Betrieb angezeigt. ( !3460, !3476)

### Termine
- Nutzer:innen, die angegeben haben, bei einem Termin (vielleicht) dabei zu sein, werden jetzt per Glocke über neue Posts auf der Termin-Pinnwand hingewiesen. ( !3336)
- Für die Beschreibung von Terminen wird jetzt Markdown genutzt. ( !3387)
- Als Ort für Termine kann jetzt direkt die Telefonkonferenz des Bezirks eingestellt werden. ( !3387)
- Der Kalender-Export wurde verbessert. Weitere relevante Informationen werden in der Terminbeschreibung angezeigt. ( !3378, !3449)

### Betriebsverantwortliche
- Warnungen über unbelegte Abhol-Slots, die Betriebsverantwortliche per E-Mail erhalten, können jetzt abgeschaltet werden. ( !3341) 
- In Betriebsprotokoll können beliebig viele Einträge nachgeladen werden. ( !3383, !3472)
- Betriebsverantwortliche erhalten nun eine Warnung, wenn Foodsaver, die sie aus einem Team austragen wollen, noch für Abholungen eingetragen sind. ( !3368)

### Meldungen
- Weitere Meldungsgründe können von den verantwortlichen Personen der Meldungsbearbeitung aktiviert werden. Damit stehen ausführlichere Meldungsgründe, sowie eine Option "Sonstiges" zur Verfügung. ( !2833)
- Die Werkzeuge der Meldungsbearbeitungsstellen wurden verbessert ( !3423, !3529)
- Im Meldungsformular ist jetzt die richtige Arbeitsgruppe mit Mailadresse angegeben, die die Meldung erreicht. Wenn also bspw. eine Meldung an ein Mitglied der Meldegruppe verfasst wird, wird jetzt die Mailadresse der Schiedsstelle angezeigt. 

### Suchfunktion
- Weitere Ergebnisse sind über die Suchfunktion erreichbar: ( !3398)
  - E-Mails aller eigenen Mailpostfächer ( !3528)
  - Termine aller eigenen AGs und Bezirke
  - Abstimmungen aller eigenen AGs und Bezirke

### Überarbeitete Seiten
Seit einiger Zeit nutzen wir für die Programmierung der Foodsharing-Seiten eine neue Technologie, die es uns ermöglicht, Änderungen deutlich besser und schneller vorzunehmen. Viele Seiten nutzen aber nach wie vor die Vorgängertechnologie und müssen nach und nach übersetzt werden. Auch in diesem Update haben wir an dieser Stelle einige Fortschritte gemacht: 
- Die Seite Profil-Einstellungen wurde mit aktuellen Technologien neu gebaut. Die Seite für die Botschafter / Orga-User wurde darin zusammengeführt. ( !3249)
- Die Profile-Seite wurde mit aktuellen Technologien neu gebaut. Zusätzlich hat die Liste der Betriebe Such- und Filterfunktionen. ( !3184)
- Die Team-Seite wurde mit aktuellen Technologien neu gebaut. ( !3248)
- Die Ausweis-Seite wurde in die Mitglieder-Seite der Bezirke integriert ( !3251, !3388)
- Die Bezirksadministrationsseite wurde überarbeitet und mit aktuellen Technologien neu gebaut. ( !3193, !3346)

### Weitere Änderungen
- In dem Fall, dass man sich erst einloggen muss, um einen foodsharing Link zu öffnen, wird man nun nach dem Login auf die richtige Seite weitergeleitet. ( !3334)
- Das Betriebsmenü wurde umsortiert, sodass Springer-Betrieb jetzt ganz unten angezeigt werden. ( !3364)
- Benutzer die länger als 5 Jahre nicht eingeloggt sind werden automatisch gelöscht. Auf der Profilseite gibt es eine Option, damit das Profil davon ausgenommen werden kann. Benutzer können dies für ihr Profil selbst setzen - Botschafter und Orga für die Profile, zu denen sie berechtigt sind.
- Bei einer neuen Bewerbung für eine Arbeitsgruppe bekommen die Admins dieser AG eine Glockenbenachrichtigung ( !3274)
- Abholungen werden auf dem Dashboard etwas länger angezeigt, sodass sie auch während der Abholung dort noch zu finden sind. ( !3382)
- Auf Visitenkarten wird keine Adresse mehr aufgedruckt ( !3362)
- In Markdown können Nutzer:innen jetzt mit `@<foodsaverId>` verlinkt werden. ( !3177)
- Der Kooperationsstatus "Ist bereit zu spenden" wurde entfernt. ( !3410)
- Essenskörbe können unabhängig von Hausadressen platziert werden. ( !3452)
- Beim Login kann das Passwort sichtbar gemacht werden ( !3459)
- Zeigt auf dem Dashboard einen Fehler, wenn die Telefonnummer nicht im gültigen Format ist. ( !3514)
